## 4. domain/ — 도메인 계층

### 4.1 `converter.py`

| 심볼 | 종류 | 역할 |
|------|------|------|
| `Converter` | 클래스 | 등록된 단위 간 길이 변환을 수행하는 도메인 서비스 |
| `Converter.__init__` | 메소드 | `UnitRegistry`를 주입받아 변환기 초기화 |
| `Converter.convert` | 메소드 | source를 meter 중간값으로 환산 후, 나머지 등록 단위별 변환 결과(`dict`) 반환 |

### 4.2 `length_unit.py`

| 심볼 | 종류 | 역할 |
|------|------|------|
| `LengthUnit` | Protocol | 길이 단위 공통 계약 — `name`, `to_meter`, `from_meter` |
| `LengthUnit.name` | property | 단위 식별자 (예: meter, feet) |
| `LengthUnit.to_meter` | 메소드 | 단위 값 → meter |
| `LengthUnit.from_meter` | 메소드 | meter → 단위 값 |
| `MetersPerUnitLengthUnit` | 클래스 | `1 unit = N meter` 비율로 정의된 길이 단위 구현체 |
| `MetersPerUnitLengthUnit.__init__` | 메소드 | 단위 이름과 1단위당 meter 비율 설정 |
| `MetersPerUnitLengthUnit.name` | property | 등록·조회에 사용되는 단위 이름 |
| `MetersPerUnitLengthUnit.to_meter` | 메소드 | `value × meters_per_unit` |
| `MetersPerUnitLengthUnit.from_meter` | 메소드 | `meter ÷ meters_per_unit` |

### 4.3 `unit_registry.py`

| 심볼 | 종류 | 역할 |
|------|------|------|
| `_LEGACY_METERS_PER_UNIT` | 상수 | 레거시 `UnitConverter.py` if/elif 단위 — Golden Master baseline |
| `create_default_registry` | 함수 | 레거시 3단위(meter/feet/yard)를 시드한 `UnitRegistry` 생성 |
| `UnitRegistry` | 클래스 | 이름으로 `LengthUnit`을 등록·조회·열거하는 단위 저장소 |
| `UnitRegistry.__init__` | 메소드 | 빈 단위 딕셔너리로 초기화 |
| `UnitRegistry.register` | 메소드 | 단위를 이름 키로 추가(또는 덮어쓰기) |
| `UnitRegistry.lookup` | 메소드 | 이름으로 단위 조회; 미등록 시 `UnknownUnitError` |
| `UnitRegistry.all_units` | 메소드 | 등록된 모든 단위 목록 반환 |

### 4.4 `exceptions.py`

| 심볼 | 종류 | 역할 |
|------|------|------|
| `UnknownUnitError` | 클래스 | 레지스트리에 없는 단위 이름 조회 시 발생 |
| `UnknownUnitError.__init__` | 메소드 | 미등록 단위 이름을 `unit` 속성·메시지에 포함 |

## 5. app/ — 애플리케이션 계층

### 5.1 `input_parser.py`

| 심볼 | 종류 | 역할 |
|------|------|------|
| `InputFormatError` | 클래스 | `unit:value` 형식이 아닌 입력 |
| `InvalidNumberError` | 클래스 | 값 부분이 유효한 숫자가 아님 |
| `InvalidNumberError.__init__` | 메소드 | 파싱 실패 원본 문자열 보관 |
| `NegativeValueError` | 클래스 | 음수 값 입력 |
| `parse_and_validate` | 함수 | 입력 파싱·검증 후 `(단위, 값)` 튜플 반환 |
| `_parse_input` | 함수 | `unit:value`에서 단위명·값 문자열 분리 |
| `_validate_value` | 함수 | float 변환 및 음수 검사 |
| `_validate_unit` | 함수 | 레지스트리 등록 여부 확인 |

### 5.2 `registration_parser.py`

| 심볼 | 종류 | 역할 |
|------|------|------|
| `_REGISTRATION_PATTERN` | 상수 | `1 cubit = 0.4572 meter` 형식 정규식 |
| `RegistrationFormatError` | 클래스 | 등록 형식 불일치 |
| `is_registration_input` | 함수 | 입력이 단위 등록 형식인지 판별 |
| `parse_registration` | 함수 | 등록 문자열 → `MetersPerUnitLengthUnit` 생성 |

### 5.3 `output_formatter.py`

| 심볼 | 종류 | 역할 |
|------|------|------|
| `Formatter` | type alias | `(source_unit, value, results) → str` 포맷터 시그니처 |
| `format_table` | 함수 | 줄 단위 사람 읽기용 텍스트 출력 |
| `format_json` | 함수 | JSON 객체 문자열 직렬화 |
| `format_csv` | 함수 | CSV(헤더 + 행) 문자열 직렬화 |
| `FORMATTERS` | dict | CLI `--format` 옵션 ↔ 포맷터 함수 매핑 |

## 8. 호출 흐름 요약

### CLI 변환 흐름

```
main()
  → load_registry()           # config_loader
  → is_registration_input()?  # registration_parser (선택)
  → parse_registration()      # registration_parser (선택)
  → run()
      → parse_and_validate()  # input_parser
      → Converter.convert()   # converter + unit_registry
      → FORMATTERS[format]()  # output_formatter
```

### GUI 변환 흐름

```
UnitConverterApp._on_convert / _on_convert_raw
  → parse_and_validate()      # input_parser
  → _show_results()
      → Converter.convert()   # converter
      → Treeview 갱신
```
